20 repositórios que transformam o Claude num estúdio de vídeo

Projetos abertos do GitHub para cortar, legendar, limpar áudio e animar. Aqui está o que cada um faz e o pedido pronto para o Claude instalar.

  1. Copie o pedidoCada cartão tem um botão que copia o pedido já com o link do repositório.
  2. Cole no Claude CodeEle instala e mostra como usar no seu vídeo.
  3. Peça ajusteNão ficou bom? Diga o que está errado, igual você falaria com um editor.

A frase de cada cartão vem da página do próprio projeto. Alguns são pesados e pedem um computador mais forte, então pergunte ao Claude antes de instalar. Peça também para ele ler o código antes de rodar qualquer coisa.
