Preciso saber programar?

Não. Você escreve em português o que quer e o Claude executa. O e-book explica cada termo para quem nunca abriu um terminal.

Preciso pagar o Claude à parte?

Sim. O Claude Code não está no plano gratuito. O plano Pro custa US$ 20 por mês (valor de novembro de 2026, confira no site oficial). O kit não inclui assinatura de nenhuma ferramenta.

Funciona com ChatGPT ou Codex?

O método é o mesmo para o Codex, que é o agente da OpenAI. O e-book compara os dois e mostra o que muda. As skills estão no formato do Claude Code.

Funciona no Windows?

Sim. O Claude Code roda em Mac, Windows e Linux. Os comandos de instalação das ferramentas mudam um pouco e o próprio Claude faz essa parte para você.
