Como fazer o ChatGPT editar no CapCut

Você entrega a narração, as imagens e um pedido por escrito. O Codex monta a linha do tempo e o projeto aparece editável no seu CapCut, pronto para você revisar.

Vídeo de exemplo montado com este método: 11 imagens, narração, legenda palavra por palavra, trilha e efeitos.

O que acontece por trás

O CapCut do computador guarda cada projeto como uma pasta com arquivos de texto. A linha do tempo inteira fica num arquivo chamado draft_info.json: cada clipe, o momento em que entra, quanto dura, os keyframes, os textos.

O Codex é o agente do ChatGPT que lê e escreve arquivos no seu computador. Se ele escreve esse arquivo do jeito certo, o CapCut abre como um projeto normal. Não é um vídeo exportado. É a linha do tempo, com tudo solto para você mexer.

O que você precisa

  • Mac com o CapCut instalado. Testei nas versões 9.8 e 9.9.
  • App do ChatGPT com o Codex e permissão para acessar suas pastas.
  • Narração em áudio. Pode ser a sua voz ou uma voz de IA.
  • Imagens ou vídeos na ordem da história, numerados.
  • Trilha e efeitos sonoros, se quiser.
  • Um projeto qualquer já criado no seu CapCut, para servir de modelo.

Passo a passo

Organize uma pasta só para o vídeo

Deixe tudo num lugar fixo. O projeto guarda o caminho de cada arquivo, então se você mover a pasta depois, a mídia fica offline.

meu-video/ narracao.wav img/01.png, 02.png, 03.png ... sfx/trilha.wav, whoosh.wav, pop.mp3

Crie o projeto modelo

Abra o CapCut, crie um projeto com uma foto, um texto e um áudio na linha do tempo e salve com um nome fácil, por exemplo MODELO. O Codex lê esse projeto para aprender como o seu CapCut escreve cada tipo de clipe. Esse foi o ponto que mais fez diferença para o projeto abrir sem erro.

Feche o CapCut

O CapCut só lê a lista de projetos quando abre. Se ele estiver aberto, o projeto novo não aparece e ainda pode ser sobrescrito.

Cole o prompt no Codex

Troque o nome do modelo e o caminho da pasta pelos seus.

Quero que você edite direto no CapCut do meu Mac, escrevendo os arquivos do projeto.

Os projetos ficam em ~/Movies/CapCut/User Data/Projects/com.lveditor.draft. Cada pasta é um projeto e o draft_info.json guarda a linha do tempo, com os tempos em microssegundos.

1. Leia o projeto "MODELO" para aprender a estrutura de foto, texto, áudio e keyframe. Não altere esse projeto.
2. Crie um projeto novo chamado "EDITADO POR IA", em 1280x720, copiando a estrutura do modelo.
3. O material está em ~/Movies/meu-video: narracao.wav, a pasta img com as imagens numeradas na ordem da narração e a pasta sfx com trilha e efeitos.
4. Transcreva a narração com o tempo de cada palavra. Troque de imagem no começo de cada frase.
5. Em cada imagem, movimento de câmera suave por keyframe, alternando aproximar e afastar.
6. Títulos curtos nos momentos fortes e legenda palavra por palavra, tudo dentro do quadro.
7. Trilha baixa sob a voz e efeitos sonoros discretos nas trocas de imagem.
8. Use caminho absoluto para cada arquivo e não mexa em nenhum outro projeto do CapCut.

No fim, me diga quantas faixas e quantos clipes você criou.

No Windows a pasta dos projetos costuma ficar em AppData\Local\CapCut\User Data\Projects\com.lveditor.draft. Eu só testei no Mac.

Abra o CapCut e revise

O projeto novo aparece na lista. Assista inteiro e ajuste o que o seu olho pedir: um corte meio segundo antes, um título menor, um efeito a menos. Essa parte continua sendo sua.

Peça a versão vertical na mesma conversa

Agora crie a versão vertical em 720x1280, em um projeto chamado "EDITADO POR IA vertical". Mesma narração e mesmos tempos. Reenquadre cada imagem para o assunto principal ficar no centro, com movimento lateral suave, e suba a legenda para a área segura do Reels.

Se algo der errado

O projeto não aparece

Feche o CapCut por completo e abra de novo.

Mídia offline

A pasta foi movida ou o caminho não é absoluto. Devolva a pasta para o lugar e peça para o Codex conferir os caminhos.

O projeto não abre

Peça para o Codex comparar o arquivo que ele escreveu com o do projeto modelo e corrigir os campos que faltam.

Imagem fora do tempo

Peça a lista de frases com o segundo de início de cada uma e diga qual troca deve mudar.
